# Code of Conduct

Global Software Timer aims to be a calm, welcoming project for people who care about local-first software, privacy, and useful desktop tools.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections gracefully.
- Keep feedback focused on the work, not the person.
- Help newcomers understand project goals and contribution standards.
- Respect privacy and do not ask contributors to share personal usage data.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Spamming issues, pull requests, discussions, or releases.
- Submitting intentionally malicious code, hidden telemetry, credential theft, or privacy-invasive behavior.
- Pressuring maintainers to merge unsafe or unrelated changes.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; block users; or report abuse to GitHub when needed.

If you see behavior that violates this code of conduct, contact the maintainer privately through GitHub.
