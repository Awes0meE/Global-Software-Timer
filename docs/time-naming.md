# 时间的命名规范

v0.4.9 起，界面、导出、海报和 README 里的时间一律按本表命名。新增或改动界面文字前先查这里；表里没有的叫法不要自己造。

## 一层套一层

整台电脑：

$$
\text{记录}\supseteq\text{活跃}
$$

每个软件：

$$
\text{运行}\supseteq\text{窗口}\supseteq\text{专注}\supseteq\text{活跃}
$$

另有两个由上面相减得到的时间：

$$
\text{后台}=\text{运行}-\text{窗口}\qquad\text{挂机}=\text{专注}-\text{活跃}
$$

同一时刻可以有好几个软件在运行、开着窗口；但专注、活跃、挂机最多只属于一个软件，所以所有软件的专注加起来不会超过记录。

## 名字表

| 名字 | 意思 | 数据 | 用在哪 |
| :-- | :-- | :-- | :-- |
| **记录** | 电脑开着、GST 在记的时间 | `daily_system_usage.recorded_seconds` | 今日记录、每日趋势、日均开机时长 |
| **活跃**（整机） | 记录里，5 分钟内有键盘或鼠标操作的部分 | `daily_system_usage.active_seconds` | 今日活跃、每日趋势、活跃率、日均活跃、热力图、连续天数、日报海报 |
| **运行** | 软件的进程在跑，有没有窗口都算 | `usage_sessions` | 概览表格的累计 / 今天、概览导出、打开次数和单次时长 |
| **窗口** | 软件开着任务栏上看得见的窗口，不管有没有选中 | `daily_software_runtime_usage.foreground_seconds` | 软件页、统计页（开着没用）、导出、软件来去 |
| **后台** | 没有窗口、进程还在跑；右下角有没有图标都算后台 | `daily_software_runtime_usage.background_seconds`；后台页另读 `daily_background_usage` | 软件页、统计导出、后台页 |
| **专注** | 窗口被选中、在最前面的时间，挂机也算 | `daily_software_focus_usage.focused_seconds` | 软件页、区间排行、开着没用、里程碑、使用天数、成就海报 |
| **活跃**（软件） | 专注里，5 分钟内有键盘或鼠标操作的部分；和整机的活跃是同一个意思 | `daily_app_usage.active_seconds`（按 `app_id`，经 `software_identity_members` 归到软件） | 概览的最常用、今日分布、往日的当日活跃 |
| **挂机** | 专注里，5 分钟以上没有键鼠操作的部分 | 专注减活跃，不另外采集 | 还没上界面，留给之后的版本 |

后台页只列后台里「右下角也没有图标」的那部分程序，名字仍叫后台。

## 运行状态

| 状态 | 意思 |
| :-- | :-- |
| **窗口运行** | 开着任务栏窗口 |
| **后台运行** | 没有窗口，进程还在跑（含右下角有图标的） |
| **未运行** | 进程不在了 |

采集时托盘和纯后台分开判定（`AppRuntimeStatus::Tray` / `Background`）。每天的时长里 `background_seconds` 是后台合计，v0.4.9 起另记其中只有托盘图标的部分 `tray_seconds`；之前的日子（以及升级当天已有的行）这一列为 NULL，表示没有分开记，不是 0。界面上两者都显示为后台运行，用同一种状态灯，托盘秒数暂不显示。

## 前缀

| 前缀 | 用法 |
| :-- | :-- |
| **今日** | 今天的数字，例如今日窗口、今日专注 |
| **当日** | 翻看往日时代替今日，例如当日活跃 |
| **累计** | 全部历史的合计，例如累计窗口、累计专注 |

## 不再使用的叫法

| 旧叫法 | 改成 |
| :-- | :-- |
| 前台、前台运行 | 窗口、窗口运行 |
| 窗口开着 | 窗口 |
| 托盘、托盘运行 | 后台、后台运行；要说清楚时写「右下角有图标」 |
| 焦点、软件页的「活跃」、活跃时长（指专注时） | 专注 |
| 共计 | 累计 |
| 状态栏、最小化到托盘（说 GST 自己时） | 后台、最小化到后台；要指图标位置时写「屏幕右下角」 |

代码里的字段名（`foreground_seconds`、`focused_seconds`、`AppRuntimeStatus::Tray` 等）不跟着改，它们不出现在界面上。
