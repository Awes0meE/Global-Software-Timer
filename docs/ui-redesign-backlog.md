以下为合并算法版之前的验收记录。合并后本分支版本为 0.2.0，软件身份和历史迁移沿用已发布的 v0.1.5。

| 2 | 前端、Tauri、Cargo、锁文件与变更日志同步为 0.1.5。Windows NSIS 安装程序可构建；发布检查限制见下。 |

**复测方式**：把环境变量 `GST_BENCH_DB` 指向已迁移的数据库副本，在新进程运行 `cargo test --manifest-path src-tauri/Cargo.toml --lib benchmark_software_first_response -- --ignored --nocapture`。基准本身只读。托盘、数据库副本、数据库明细均不随截图发布。

**原生窗口验收**：后端基准复测用时 109 毫秒，返回 194 个已发现软件。另提供从点击「软件」到列表绘制的原生验收，随后检查 B 版设置页。先运行 `npm.cmd run build`，再将 `GST_BENCH_DB` 指向一次性数据库副本，运行 `cargo run --manifest-path src-tauri/Cargo.toml --release --features tauri/custom-protocol --example gst_backlog_qa`。原生验收会对副本执行正常启动恢复。当前环境中 WebView2 的 GPU 子进程因访问被拒绝而退出，尚无原生首屏耗时。

**提交前复测**：`npm.cmd run check` 通过，包括 72 项前端测试、99 项 Rust 测试、生产构建和格式检查。npm 依赖审计恢复，报告 0 项已知漏洞。MSI 的 WiX ICE 校验仍待在能访问 Windows Installer 服务的环境验证。

| 1 | P1 | 用户 | 鼠标移到右上角“导出”“更多”上时，“该功能暂未完成”提示被窗口顶部的最小化/最大化/关闭标题栏挡住。 | `src/styles.css` 的 `.unavailable-tooltip-bubble` 固定显示在按钮上方（`bottom: calc(100% + 8px)`）；页头按钮离网页顶部只有约 18px，提示超出网页区域后被系统标题栏盖住。日期按钮也有同样风险。 | 页头里的提示改为显示在按钮下方，或者根据可用空间自动选择上方或下方。 | 在 1440×900 和 1180×760 窗口下，悬停或键盘聚焦“日期”“导出”“更多”时，提示完整可见，不被标题栏或窗口边缘裁切。 |
| 2 | P1 | 用户 | 版本号还没有更新，侧栏仍显示 `V0.1.4`。 | `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 仍是 0.1.4；`CHANGELOG.md` 的改动记在 Unreleased 下。 | 确定新版本号（建议 0.1.5），三处元数据和 CHANGELOG 一起更新。按项目规范，版本号单独作为 `chore(release)` 提交，放在功能提交之后。 | 侧栏、安装包和 CHANGELOG 显示同一个新版本号，`npm.cmd run check` 通过。 |
