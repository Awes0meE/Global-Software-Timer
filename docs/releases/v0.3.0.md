# Global Software Timer v0.3.0

- 侧栏的「统计」页正式开放。可以选近 7 天（默认）、本周、本月、近 30 天、今年，或自定义最长 366 天的区间，每个总数都和前一段同样长度的区间对比。
  - 每日趋势：用走纸记录仪的样式画出每天的记录时长和活跃时长，活跃占比是一条走线，日均活跃时长是一条虚线。
  - 区间排行：按区间内的焦点时长给软件排名，标出新上榜和名次升降。
  - 开着没用：列出窗口开着至少 5 小时、但焦点时长不到其中 5% 的软件；托盘和后台时长不算在内。
  - 会话和作息：每个软件的打开次数、平均和最长会话；工作日和周末的日均活跃时长、日均计时器运行时长，以及每天第一条和最后一条记录时间的中位数。
  - 开始记录软件明细之前的日子标为「无软件明细」，不计入软件相关的数字，也不当作 0。
- 侧栏的「成就」页正式开放。
  - 活跃热力图：在一块液晶屏里按月排出近 90 天、近半年或近一年每天的活跃程度，右侧显示当前连续和最长连续使用天数。
  - 个人纪录：活跃最久的一天，以及单个软件焦点最久的一天。
  - 里程碑：软件累计焦点时长达到 10、50、100、500、1000 小时时点亮对应铭牌，另有 6666 小时的终极铭牌。
  - 软件来去：近 30 天新出现的软件和 30 天没打开的软件；累计窗口时长不到 1 分钟的程序（比如安装程序）不计入。
- 只记录，不设目标：活跃不到 5 分钟的日子按「没用」算，免得开机看一眼也被记上。页面上没有目标、倒计时或「保持连续」之类的提醒，也不发通知。
- 两个页面默认不含隐藏软件，可以用「包含隐藏软件」开关临时加进来；整机的总时长不受影响。两页只读取本机已有的记录，不新增采集，也不改数据库。
- 页头的单日日期按钮现在只出现在「概览」和「后台」；「软件」「统计」「成就」「设置」不再显示。

## Windows 10 / 11 x64

现有 v0.2.x 用户可以直接覆盖升级，本机的历史记录和设置都会保留，数据库结构不变。

- 常规安装或升级使用 `Global.Software.Timer_0.3.0_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.3.0_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
