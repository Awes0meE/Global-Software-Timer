# Global Software Timer v0.4.1

- 侧栏当前页改为一颗凸起的键帽，不再用侧边竖条；软件页「特别关注」和后台页的吸顶表头改为凸起的键条，深色主题下不再沉成近黑。
- 后台页顶部的概况改为一条墨水屏，六个像素读数：正在后台运行、进程、当前合计 CPU、当前合计内存、今日 CPU 时间、今日出现，都由后台页原有的数据算出。
- 成就页热力图每个月等宽，连续天数、区间读数和图例移到屏幕底部的一条读数栏里。
- 去掉了各页的说明小字：概览读数下方、今日分布总时长下方，后台、统计、成就页上，以及隐藏软件列表每一行下面。仍需要说明的地方，改在标题旁的「?」气泡里（隐藏软件列表、后台进程、开着没用、作息）；统计、成就页各项数字的口径写在 README 的口径表里。
- 统计页的「作息」移到「每日趋势」之后，「会话」放到最后。
- 今日分布色条改为不发光的平面色段，深色主题下亮色段不再显得比暗色段高。这一条取消了 v0.4.0 设计里「深色下每段带同色微光」的做法。
- 每日趋势走纸记录仪去掉两端的滚轴细条；「今日活跃」的图例色块和表盘内圈一致。
- 浅色主题下软件图标不再垫灰底，改为沿图标轮廓的一圈细边，白色图标也看得清。
- 修正：热力图最后一行月份较少时，行间刻线也画满整宽；125% 显示缩放下后台概况条和热力图的像素读数保持清晰，标签不再被裁掉；Windows 对比度主题下键帽去掉高光，后台表头和表格之间有分隔线，浅色图标细边也去掉。
- 不改数据和口径：采集、schema、各页的时长算法都不变。

## 升级说明

数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.0 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.1_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.1_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
