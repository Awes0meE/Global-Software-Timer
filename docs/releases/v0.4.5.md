# Global Software Timer v0.4.5

- 界面按苹果的设计规范打磨了一遍：
  - 界面字体从 Segoe UI、微软雅黑和 Bahnschrift 换成 Inter 和思源黑体，就是海报已经在用的那两套字体，安装包不变大。字重整体轻一档：标题和软件名 600，次要强调 500，正文 400。数字一律用等宽数字。墨水屏上的像素字体不变。
  - 侧栏改成一张浮在窗口里的玻璃卡片，离窗口上下各 10 px、左边 12 px，背景光晕从它下面透过去。
  - 侧栏可以收成一列图标：点导航下面版本号右边的键收起或展开，指向图标（或用 Tab 移到它上面）会显示页面名称。GST 会记住你的选择。窗口窄于 1200 px（界面尺寸）时侧栏自动收起，这时手动展开只维持到窗口再次越过这个宽度。
  - 「设置」→「显示」新增「文字大小」：「标准」（默认）或「大」。「大」把整个界面（文字、图标和墨水屏）一起放大到 125%，像 Windows 的显示缩放一样，像素数字照样清楚。这时窗口最小为 1280 × 800（更小的窗口会被放大），侧栏收成图标。改了马上生效，启动时在页面出现之前就生效，「导入设置…」后也生效。设置文件带上这一项，旧文件照常导入。
  - 墨水屏在每一页都离面板边缘 8 px（以前是 8 到 14 px），圆角 8 px，和面板圆角同心。
  - 墨水屏以外的文字只用一套字号阶梯：对话框标题和趋势总计 17 px（原来 18），「今日分布」总计和个人纪录数字 26 px（原来 30 和 28），里程碑档位 22 px（原来 24）。
  - 中文标题、表头和标签不再加字距；只有 `CSV`、版本号这类拉丁大写字母、数字和「终极成就」铭牌保留字距。
  - 面板里的滚动列表在还有内容的那一边淡出最后 16 px，不再把一行切成两半；放得下的列表和已经滚到头的那一边不淡出。「后台」表格有吸顶表头，只在底部淡出。「统计」「成就」「设置」整页滚动，往下滚后在页面标题下面淡出。
  - 点了还要再选一步的命令以「…」结尾：「软件」的「添加…」、「成就」的「导出成就…」，以及所有打开 Windows 保存对话框的导出：「导出软件清单…」「导出后台记录…」「日报海报…」「当日明细…」「区间汇总…」「每日明细…」「导出设置…」「备份全部数据…」。只打开菜单的键（「导出日报」「导出报表」「迁移与备份」）不变。
  - 「软件」页只留一个深色主按钮：「隐藏软件列表」的「添加…」改成和旁边「编辑」一样的浅色按钮。
  - 新增快捷键：`Ctrl+1` 到 `Ctrl+6` 按顺序打开侧栏的各页（跳过还不能用的「时间轴」），`Ctrl+,` 打开「设置」，`Ctrl+←` / `Ctrl+→` 在「概览」和「后台」切换日期，到头时和 `‹ ›` 键一样停住。输入框和打开的对话框里这些键照常用。README 里列出了这些快捷键。
  - 圆形的 `?` 帮助键看起来还是 16 px，但 28 px 范围内都能点到、都有悬停效果。
  - 「统计」趋势图下面的「今天」指示灯不再碰到日期文字。
- 去掉最后的说明小字：
  - 侧栏去掉「本地软件时长记录」和「数据只保存在本机」；「设置」→「数据存储」仍写着「仅本机」。
  - 「设置」里的各行只显示标题。空列表只显示一行标题，下面不再有提示。
  - 第一次关闭窗口的对话框只留一句「GST 在状态栏里运行时才会记录，退出后就不再记录。」，让你知道退出后就不记了。
  - 「从备份恢复」对话框里的两段提醒和「设置」底部的隐私说明保留。
- 性能：「概览」刷新快了约 4 倍。在一份用了六个月的数据库上，每 5 秒一次的汇总从 44 ms 降到 12 ms。现在每个软件的名称、身份和程序路径每次只算一遍，不再按每段记录各算一遍。显示的数字不变。
- 数据库瘦身：用了很久的数据库会从约 200 MB 缩到几 MB。
  - v0.1.x 及以前的版本每次扫描都给每个运行中的软件记一条心跳日志。现在没有地方读这份日志，会话自己也记着心跳。
  - 这个版本第一次启动时删掉这些记录并压缩数据库文件。删之前先把完整数据存到数据文件夹的 `backups\GST-清理前-<日期>-<时间>.db`，只留最新的一份。存不了这份副本就什么都不删。
  - 文件变小后，升级前的备份、「备份全部数据」和「从备份恢复」都更快。
  - 恢复一份旧的备份会把这些记录带回来，下次启动时按同样的方式再删掉。
- 不改采集和口径：各页的时长算法不变，数据库结构仍为 schema 3。

## 隐私

清理心跳日志之前存的那份副本放在数据文件夹的 `backups\` 里，和别的数据一样只留在这台电脑上。侧栏收起还是展开只存在应用窗口的本地存储里，「文字大小」和其他设置一样存在本机数据库里。没有新增插件，不联网，也不上传任何东西。具体见 `PRIVACY.md`。

## 已知事项

「文字大小」选「大」时的 125% 显示，以及第一次启动时的清理，要在装好的安装版里先确认一次。

## 升级说明

数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。升级后第一次启动时，GST 先存一份完整副本，再删掉早期的心跳日志，大约要两秒。确认数据没问题后，可以自己删掉 `backups\` 里那份 `GST-清理前-…db`。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.5_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.5_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
