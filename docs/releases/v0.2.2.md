# Global Software Timer v0.2.2

## 首屏和任务栏

- 概览先加载仪表盘，打开「软件」时再加载软件页和拼音搜索。打开列表可直接读取最近一次完成的采样，屏幕外的行延后绘制。
- Windows 任务栏、窗口标题栏和启动器使用新版金属表盘时钟。安装包包含 16 到 256 像素的十档图标，通知区域保留适合小尺寸的粗指针版本。

## 计时与显示

- 采样异常会回滚，下一轮继续记录。侧栏显示最近一次采样的状态。窗口枚举失败时，前台计时需要有效的窗口证据。
- 同一软件包的名称和图标稳定对应同一个程序。图标暂时读取失败会自动重试。从其他安装路径再次启动 GST 也能唤出主窗口。
- 概览和后台页区分读取中、失败和空数据。运行列表区分前台与托盘，后台 CPU 时间遵循时长偏好，已退出进程的内存标为今日峰值。

## Windows 10 / 11 x64

现有 v0.2.x 用户可以直接升级，沿用本机历史和设置。

- 日常升级使用 `Global.Software.Timer_0.2.2_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.2.2_x64_en-US.msi`。

可用附件 `SHA256SUMS.txt` 核对安装包。
