# Global Software Timer v0.4.6

- 「设置」新增「关于与反馈」一组，放在「隐私」上面：
  - 「当前版本」显示版本号，点「更新日志」打开各版本的发布说明。
  - 「报告问题」和「提建议」打开 GitHub 上的问题表单和建议表单。
  - 「QQ 交流群」显示群号 937943526，「复制群号」把群号复制下来，「加入」打开加群邀请。
  - 这些页面都在你的默认浏览器里打开。GST 只把四个固定地址（三个 GitHub 页面和 QQ 加群邀请）交给 Windows，别的地址一概打不开。
- 「当前版本」旁边新增「检查更新…」：
  - GST 默认永不联网。每次点「检查更新…」都会先弹窗问你：「检查更新需要联网。GST 只会向 GitHub 查询最新的版本号，不会发送任何使用记录。」只有点了「联网检查」才会发出请求，点「取消」什么都不发。每次都要重新同意，不会记住。
  - 已经是最新版本时显示「已是最新版本」，连不上时显示「无法连接到 GitHub」。
  - 发现新的正式版时，再弹出「发现新版本」，列出当前版本、新版本和安装包大小，再问你一次。
  - 点「更新并重启」后，GST 先把完整数据备份到数据文件夹的 `backups\GST-更新前-<版本号>-<日期>-<时间>.db`（只留最新的一份），备份不成就不下载；然后下载安装包并显示进度，校验签名，安装，再自动重启。
  - 下载时点「取消」会停止下载，什么都不装。任何一步失败都会提示「更新没有完成」，当前版本照常运行。
  - 没有任何自动或后台请求：启动时、定时和后台都不会检查更新。
- 许可证从 MIT 改为 GPL-3.0-or-later：你仍然可以自由使用、学习、修改和分享 GST，但分发修改过的版本时，要同样以 GPL 开源并提供完整源代码。v0.4.5 及更早的版本仍按 MIT 授权。「全局软件计时器」「Global Software Timer」「GST」这些名称和时钟图标不随代码授权，修改后的版本要换自己的名称和图标，见 `TRADEMARKS.md`。
- 不改采集和口径：各页的时长算法不变，数据库结构仍为 schema 3。

## 隐私

GST 唯一会联网的时候，是你点了「检查更新…」并在弹窗里同意：只访问 GitHub，先查询最新版本的清单 `latest.json`，你同意更新时再下载安装包；不发送任何使用记录、设置或标识。更新前的那份备份放在数据文件夹的 `backups\` 里，只留在这台电脑上。「更新日志」「报告问题」「提建议」和「加入」由浏览器打开、由浏览器联网，不是 GST。具体见 `PRIVACY.md`。

## 已知事项

这是第一个带更新签名的版本：一键更新要等从 0.4.6 升到之后的版本时才能用上。安装包仍然没有 Windows 代码签名，SmartScreen 可能会提示，点「更多信息 → 仍要运行」即可。

## 升级说明

v0.4.5 及更早的版本没有「检查更新…」，需要手动下载安装一次 0.4.6，之后就可以在软件里升级了。数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。从 v0.4.4 或更早的版本直接升到 0.4.6 时，第一次启动也会做一次 v0.4.5 的清理：先存一份完整副本 `backups\GST-清理前-…db`，再删掉早期的心跳日志。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.6_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.6_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值，`latest.json` 是给「检查更新…」读取的版本清单。

## 代码签名 / Code signing policy

本版本的安装包没有代码签名，已向 SignPath Foundation 申请免费签名，详见 [代码签名政策 Code signing policy](../../CODE_SIGNING_POLICY.md)。
