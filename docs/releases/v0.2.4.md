# Global Software Timer v0.2.4

- 软件图标按程序内嵌的最大尺寸读取（最大 256px），再统一缩放到 96px，在 125%、150% 显示缩放下也保持清晰。同时修正了图标边缘发暗的问题，没有透明通道的老式图标也会保留黑色描边。
- 图标改走本地 `gsticon` 协议，读到一个就显示一个，不用等下一次刷新。读过的图标缓存在 `%LOCALAPPDATA%\com.globalsoftwaretimer.app\icons\`，重启后直接读取；缓存文件名是哈希值，写入超过 90 天的会在启动时清理。
- 「已发现软件」和运行时长里过滤掉更多噪声：
  - 常驻服务：SQL Server、Wacom、Bonjour、Office 即点即用、FlexNet、ASUS GameSDK、Microsoft Gaming Services。
  - 辅助进程：BitDock、Eternal、MATLAB、SolidWorks、搜狗、WPS 等软件自带的辅助进程。
  - 命令行工具：由其他程序启动的 git、rustup，以及 Codex 运行时。
  - 安装程序：从临时目录、「下载」文件夹或更新程序目录运行的程序。

  「后台」页仍会列出这些程序，数据库里的历史记录不变。
- 「后台」页可以点击表头排序：第一次点击从高到低，再点一次反过来，没有数值的行始终排在最后；默认仍按今日 CPU 时间排序。
- 「特别关注」表里「今日活跃」的说明气泡不再被表格裁掉：下方空间不够时改为向上弹出，表格滚动时也保持在窗口内。
- Tauri 依赖的 `serde_with` 升级到 3.21.0，修复安全公告 GHSA-7gcf-g7xr-8hxj。本应用没有用到受影响的功能，行为不变。

> 注意：凡是从「下载」文件夹直接运行的程序，现在都会被当作安装程序，不再计时。如果你习惯把便携软件放在「下载」里直接打开，请把它移到别的文件夹。

## Windows 10 / 11 x64

现有 v0.2.x 用户可以直接覆盖升级，本机的历史记录和设置都会保留，数据库结构不变。

- 常规安装或升级使用 `Global.Software.Timer_0.2.4_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.2.4_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
