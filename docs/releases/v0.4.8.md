# Global Software Timer v0.4.8

- 切换不再生硬：点左边栏换页、在「概览」「后台」换日期（`‹ ›`、日历、`Ctrl+←` / `Ctrl+→`）、在「统计」换时间范围、在「成就」换热力图范围时，旧内容和新内容在原地互相溶解，大约 0.4 秒，中间不会闪一下空白。
- 左边栏当前页的凸起键、各处分段按钮的选中块，会从原来的位置滑到新位置。
- 弹窗打开时从稍小的尺寸浮起，关闭时遮罩淡出、窗口微微下沉，不再一下子消失；日历和导出菜单收起时朝按钮的方向收回去。
- 「设置 → 显示」新增「动画速度」：快、中（默认）、慢，换页、滑块、弹窗、菜单和提示框的动画都跟着这一档变快或变慢。打开「减少动画」或者 Windows 关闭了动画效果时，这一项变灰，所有动画照样关掉。「导出设置」和「导入设置」会带上这一项。
- 读取很快时不再先变暗：换日期、换范围后新数字一读到就换上，读取超过 0.3 秒才会先把旧数字变暗（「统计」页同时显示「正在读取…」）。回到去过的「软件」「后台」「统计」「成就」页，会先显示上一次的内容，再无缝换成最新的，不会先闪一行「正在读取…」。这些内容只在 GST 运行期间留在内存里，不保存。
- 数字换了字体：墨水屏以外的数字（表格里的时长、统计、纪录、里程碑、日期和版本号）改用 Oxanium，字重 500，高度和以前一样；数字和后面的单位之间留一点空隙（`412.6 小时`、`18 分钟前`）。「统计」页走纸图下方的日期和活跃 / 记录数值也用它。字体随安装包附带（17 KB，SIL OFL 1.1）；墨水屏的像素字体和海报字体不变。
- 「成就」页：鼠标指着已点亮的里程碑格时，它会浮起来（浅色主题变白并带柔和的投影，深色主题提亮一档、下方有淡淡的光），不再发出主题色的光。「终极成就」那一格保留主题色描边。
- 「概览」读数屏里「最常用」的图标（以及「设置」读数屏上的时钟）显示原本的颜色，不再半褪色，像 Claude 这样颜色鲜艳的图标不会再显得发灰。
- 不改采集和口径：各页的时长算法不变，数据库结构仍为 schema 3。

## 隐私

不新增任何联网，也不新增采集内容。新的「动画速度」和其他设置一样只存在本机数据库里（`ui.motion_speed`）；回到页面时显示的上一次内容只在内存里，GST 退出就没有了。GST 唯一会联网的时候仍然是你点了「检查更新…」并在弹窗里同意，具体见 `PRIVACY.md`。

## 升级说明

已经装了 v0.4.6 或 v0.4.7 的话，可以在「设置 → 关于与反馈 → 当前版本」点「检查更新…」，同意后一键升级到 0.4.8：GST 会先备份数据，再下载、校验签名、安装并重启。v0.4.5 及更早的版本没有「检查更新…」，需要手动下载安装一次。数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.8_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.8_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值，`latest.json` 是给「检查更新…」读取的版本清单。

## 代码签名 / Code signing policy

本版本的安装包没有代码签名，已向 SignPath Foundation 申请免费签名，详见 [代码签名政策 Code signing policy](../../CODE_SIGNING_POLICY.md)。
