# Global Software Timer v0.4.2

- 概览和后台页可以翻看往日：页头多了一组日期键，`‹` 往前一天、`›` 往后一天，点中间的日期弹出日历直接跳到某一天；看往日时右边多一个「今天」键，一点就回到今天。
- 日历是一张印在墨水屏上的普通日历：周一在前，点顶上的「2026年11月」可以切到月份视图，只标出今天、选中的日子，以及开始记录之前和今天之后选不了的日子。
- 往日只是回看已经存下的记录：概览的读数和表格改叫「当日记录」「当日活跃」「当日」，「正在运行」收起，「当日分布」占满右栏；后台页改看那天的峰值进程数和峰值内存，不显示当前 CPU 和状态。看哪一天不会保存，重新打开 GST 总是回到今天；停在今天时照常实时刷新，过了午夜自动换到新的一天。
- 统计页的「自定义」区间改用同一个日历，先点开始日、再点结束日，不再是两个日期输入框。
- 各页页头有了自己的导出键，都存成 CSV 表格：
  - 概览「导出日报」：正在看的那一天，每个软件的当日运行、当日活跃和累计运行（不含隐藏软件）。
  - 软件「导出软件清单」：特别关注、隐藏、已发现的每个软件各一行，写明分组、状态、最近打开，以及今日和累计的前台、后台、专注时长。
  - 后台「导出后台记录」：正在看的那一天，每个后台程序的峰值进程数、峰值内存、后台时长和 CPU 时间。
  - 统计「导出报表」：当前区间里每个软件的排名、焦点、窗口开着、开着没用、打开次数、平均单次和最长单次，跟随「包含隐藏软件」开关。
  - 表格是带 BOM 的 UTF-8，Excel 直接打开不乱码；时长是两位小数的小时；不含任何程序路径；可能被表格软件当成公式的内容前面加一个 `'`。成就页没有导出键。
- 设置页页头新增「迁移与备份」：
  - 「导出设置」把你改过的主题、时长格式、关闭窗口时的行为，以及特别关注和隐藏两个名单存成 JSON；不含开机自启、使用记录和安装路径。
  - 「导入设置…」先列出会改动的设置和名单会多出几个，确认后才写入；只往名单里加，不删本机已有的条目。
  - 「备份全部数据」把整个数据库完整复制一份，备份时照常记录。现在还没有「从备份恢复」按钮，需要时按 README「迁移与备份」一节的步骤手动换库：先从托盘退出 GST，把现有数据库改名留着，再把备份改名放进去。
- 保存时弹出 Windows 的保存对话框，默认打开「下载」文件夹，文件名已经填好；保存后提示「已保存」，可以点「在文件夹中显示」。点取消什么都不写，保存失败会提示「保存失败」，不会留下写了一半的文件。
- 页头和「今日分布」「正在运行」面板里的「更多」按钮都去掉了，页头不再放用不了的占位键；页头的键改成和侧栏当前项一样的凸起键帽。
- 后台页顶部的墨水屏加高，标签和数字之间留出更多空间。
- 不改采集和口径：各页的时长算法不变。

## 隐私

导出的表格、设置文件和备份，只在你在保存对话框里点了保存后，写到你选的那个位置；不会自动写到别的文件夹，也不会上传。表格和设置文件不含程序路径；备份是整个数据库，包含全部使用记录和后台程序的路径，分享前请留意。每种文件的内容见 `PRIVACY.md`。

## 升级说明

数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.2_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.2_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
