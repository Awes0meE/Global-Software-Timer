# Global Software Timer v0.2.1

## Edge 计时修复

开启「启动加速」后，Edge 会提前启动一个没有窗口的主进程。以前，在这个进程中打开浏览器窗口后，计时器仍可能把 Edge 显示为「后台运行」，漏记前台时长。现在，检测到任务栏窗口后就会开始记录；关闭最后一个窗口后，单独留在后台的预加载进程也会停止计入前台。渲染、GPU 和嵌入式 WebView 子进程继续按辅助进程处理。

修复从升级后的采样开始生效。旧版本漏记的时长没有足够数据可以回填。

## 从上一版升级

从 v0.2.0 或 v0.1.5 升级会继续使用现有数据库、历史记录和设置，数据库版本仍为 2。从 v0.1.4 或更早版本升级，请先退出托盘程序并备份数据库，首次启动会执行 v0.1.5 引入的迁移。

从上一个公开版本 v0.1.5 升级，还会获得 v0.2.0 的明暗主题、液晶概览和新版设置页。[界面更新说明](https://github.com/Awes0meE/Global-Software-Timer/blob/v0.2.1/docs/releases/v0.2.0.md)

## Windows 10 / 11 x64 安装包

- 日常安装或升级请选择 `Global.Software.Timer_0.2.1_x64-setup.exe`。
- 使用 Windows Installer 部署时请选择 `Global.Software.Timer_0.2.1_x64_en-US.msi`。

安装包未签名，Windows SmartScreen 可能提示未知发布者。可使用附件 `SHA256SUMS.txt` 核对下载文件。
