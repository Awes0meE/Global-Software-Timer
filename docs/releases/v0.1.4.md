# Global Software Timer v0.1.4

Windows 10/11 x64 · 2026-11-17

## Changes
- Prevent sleep-sized observation gaps and clock rollback from inflating recorded time; split daily counters at local midnight.
- Make tracker writes atomic, reduce heartbeat writes, and close sessions during normal exit.
- Add transactional schema versioning and separate read-only summary connections.
- Pause polling while hidden and prevent stale responses from overwriting software-list changes.
- Add optional hours/minutes display and improve background-helper filtering.
- Update affected frontend development dependencies and enforce npm audit in CI.
- Stop installer staging when validation or packaging fails.

## Validation
Publication requires the complete project check (66 frontend tests, 95 Rust tests, formatting, frontend build, release-script failure regressions and npm audit) followed by successful Windows installer builds. SHA256SUMS.txt contains installer hashes.

## Install or update
Use Global.Software.Timer_0.1.4_x64-setup.exe for the normal per-user installation, or the x64 MSI for managed installation. Exit GST before updating. The app keeps the existing local database and settings; back up your data before upgrading. No historical event deletion or database compaction is performed.

Installers are unsigned and Windows may display a SmartScreen warning. No automatic updater, telemetry, account or cloud upload is added.

Real-device sleep/hibernate acceptance, Windows power notifications, historical data repair/cleanup, backup/restore UI, and accounting-model redesign remain separate work.
