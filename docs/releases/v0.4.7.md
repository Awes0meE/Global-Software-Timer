# Global Software Timer v0.4.7

- 页面顶部（标题和日期、导出按钮旁边的空白处）现在可以像标题栏一样按住拖动窗口；在页面上拖动也不会再选中标签和读数，只有输入框和错误提示还能选中文字。
- 右下角的提示框（「已复制群号」「已保存」等）会从下方轻轻升起，消失时往下沉并淡出；底色换成带主题色的浅一档灰（失败时是淡红色），和深色背景分得开，眼神不好也能看清。打开「减少动画」后没有动效。
- 「检查更新…」的结果都改成弹窗，点「确定」才关闭：「已是最新版本」（会写出当前版本号）、「无法连接到 GitHub」、「更新没有完成」。
- 「成就」页：
  - 已点亮的里程碑格整格都能点，鼠标放上去边缘会微微发亮。点开后列出达到这一档的全部软件，按累计焦点时长从多到少，每行写焦点时长，以及这一档的达成日期或已经升到的更高档。点框外、点「×」或按 Esc 关闭。没点亮的格子不能点。
  - 活跃热力图不再分「不到 1 小时 / 不到 3 小时 / 3 小时以上」三档，而是按当天活跃时长线性加深，12 小时及以上最深；没用的日子还是空框，还没到的日子是虚线框。
- 「概览」→「今日分布」去掉了顶部的合计。它只合计能归到列出软件的活跃时间（GST 自己的窗口、桌面和系统窗口、隐藏的软件都不算），所以总比「今日活跃」少一点，看起来像两个对不上的总数。彩条和列表保留，每行在任何窗口宽度下都显示百分比，「大」字号下能露出 4 行。
- 「设置」顶部的读数屏改成「已记录 N 天」「本机数据 X MB」和标语「绝对隐私，数据只存本地 / 不联网、不登录、零遥测、零请求」；版本号只在「关于与反馈 → 当前版本」显示。
- 安全：更新插件 tauri-plugin-updater 从 2.12.0 升到 2.14.1，去掉了被三条安全告警（其中一条严重）标记的 `zip` 4.6.1。GST 的更新从不处理 zip 包、下载后先校验签名，所以此前并不能被利用，但有问题的代码已经不在了。连带升级了 Tauri 2.12.7。
- 不改采集和口径：各页的时长算法不变，数据库结构仍为 schema 3。

## 隐私

不新增任何联网。「本机数据」只读取数据文件夹里数据库文件的大小，不读内容、不上传。GST 唯一会联网的时候仍然是你点了「检查更新…」并在弹窗里同意，具体见 `PRIVACY.md`。

## 升级说明

已经装了 v0.4.6 的话，可以在「设置 → 关于与反馈 → 当前版本」点「检查更新…」，同意后一键升级到 0.4.7：GST 会先备份数据，再下载、校验签名、安装并重启。v0.4.5 及更早的版本没有「检查更新…」，需要手动下载安装一次。数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.7_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.7_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值，`latest.json` 是给「检查更新…」读取的版本清单。

## 代码签名 / Code signing policy

本版本的安装包没有代码签名，已向 SignPath Foundation 申请免费签名，详见 [代码签名政策 Code signing policy](../../CODE_SIGNING_POLICY.md)。
