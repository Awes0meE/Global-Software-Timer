# Global Software Timer v0.2.0

Windows 10 / 11 x64

## 更新内容

- 概览使用液晶表盘显示今日记录和活跃时长。「正在运行」同时列出拥有任务栏窗口的软件和已识别的托盘软件。
- 设置页顶部显示版本和数据存储方式。主题可跟随 Windows，也可以选择浅色或深色。
- 软件和后台页面采用同一套明暗界面。后台进程列表展示当前 CPU、内存以及今日的后台运行时间和 CPU 时间。
- 概览、软件和后台页面先显示使用数据，应用图标由后台线程读取。

## 从 v0.1.5 升级

v0.2.0 沿用 v0.1.5 的数据库版本 2 和软件识别算法。已有的时长记录、特别关注和隐藏列表继续使用。Windows 11 支持托盘软件识别，Windows 10 沿用窗口识别。

从 v0.1.4 或更早版本升级时，首次启动仍会执行 v0.1.5 引入的数据库迁移。若要保留回退到旧版本的能力，可先退出托盘程序并备份数据库。
