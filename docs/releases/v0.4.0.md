# Global Software Timer v0.4.0

- 全部界面换成云母玻璃外壳加墨水屏读数，浅色、深色两套主题都换了；默认仍跟随系统，设置页的 跟随系统 / 浅色 / 深色 不变。
- 概览表盘外加了 96 条刻线，每 15 分钟一条；「今日记录」「今日活跃」两个大号读数后面会留一层上一次显示值的淡残影，跨天或读数变小时不留残影。
- 关闭 Windows「透明效果」后，下次打开或还原窗口时面板改为不透明，文字照样清楚；系统要求减少透明或不支持模糊时也一样。Windows 对比度主题下，文字和焦点环都看得见。
- 信号橙只表示此刻正在发生的事，例如「正在记录」指示灯和「前台运行」状态点；选中和焦点改用蓝色，错误和警告用单独的红色。
- 不改数据和口径：采集、各页的时长算法、页面布局和文字都不变。这一版只多读一项 Windows「透明效果」开关，用来决定面板怎么显示，不保存、不上传，详见 `PRIVACY.md`。

## 升级说明

数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.0_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.0_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。

## 发布后验收

发布前已在浏览器预览里用示例数据完成截图、布局、对比度和帧率验收。下面几项要在装好的正式版上做，发布时尚未完成：

- 关闭、再打开 Windows「透明效果」并重新打开窗口后，面板变为不透明、玻璃恢复（验收 6）。
- Windows 对比度主题下所有文字和焦点环都看得见（验收 7）。
- Windows 10 上的显示与 Windows 11 一致（验收 8）；没有 Windows 10 实机或虚拟机时，记为未在 Windows 10 实测，以 Windows 11 加透明效果关近似。
- 100% / 125% / 150% 显示缩放下像素读数边缘清晰（验收 9）。
- 拖动窗口、在 1180×760 和最大化之间调整大小，没有可见的卡顿或撕裂；概览页静止 1 分钟，WebView2 的平均 CPU 不比 v0.3.1 高出 1 个百分点以上（验收 11，性能验收第 2、3 行）；透明效果关时再测一遍。

发布后在本机逐项验收，结果记入 `docs/CURRENT_STATE.md`；不达标会发补丁版。
