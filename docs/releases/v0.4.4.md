# Global Software Timer v0.4.4

- 设置页新增两组：「外观」里是「主题」「主题色」「墨水屏配色」，「数据」里是「数据文件夹」「从备份恢复」。「运行」多了「启动时打开」，「显示」多了「每周起始日」和「减少动画」。原有各行的文字和行为不变。
- 「主题色」有 8 种：跟随 Windows、蓝、青、绿、紫、玫红、琥珀、石墨。
  - 主题色用在开关、选中项、侧栏当前页的图标、焦点框、选中的文字和搜索命中上。
  - 除了蓝，每种主题色也会给背景光晕染色。光晕比样稿略淡一些，所以光晕上的文字和以前一样清楚。
  - 默认是蓝，看起来和 v0.4.3 完全一样。
  - 「跟随 Windows」用 Windows 的强调色，太浅或太深时自动调亮或调暗，保证看得清。读不到颜色时用蓝的颜色，光晕仍然染色。每次窗口重新显示时都会再读一次。
  - 橙色的「正在」指示灯、各软件的颜色、警告和海报都不跟着变。
- 「墨水屏配色」有 5 套纸色和墨色，所有墨水屏一起换：极光（默认，就是现在的样子）、石墨、夜蓝、暖纸、墨绿。每套都有浅色和深色两种纸。海报保持原样。
- 「每周起始日」可以选周一或周日，影响五个地方：日期选择日历、统计页的「本周」、成就页热力图的月份、每日趋势上按周的标签，以及软件页「这周X」「上周X」的最近打开时间。星期名称、工作日和周末、CSV 表格、海报和统计页的对比区间不变。
- 「启动时打开」选 GST 启动时显示哪一页：概览、软件、后台、统计或成就。开机自启、自己打开、从备份恢复后重启都按这个来，直接打开那一页，不会先闪一下概览。从托盘打开窗口时仍停在你离开时的那一页。
- 「减少动画」打开后，即使 Windows 没要求，也关掉动效：开关、对话框和提示照样变化，只是不再有过渡；「正在记录」指示灯常亮，不再呼吸。关闭时照旧跟随 Windows 的设置。
- 「数据文件夹」→「打开」在文件资源管理器里打开存放数据库的文件夹。打不开时提示「无法打开数据文件夹」。
- 「从备份恢复」→「选择备份…」可以在应用里恢复整库备份，不用再手动换文件。
  - 选一个 `.db`、`.sqlite3` 或 `.sqlite` 文件。GST 先检查它的一份副本，这一步不碰现在的数据。
  - 对话框显示文件名、记录的时间范围、软件数量和文件大小，点「恢复并重启」后替换数据并重启 GST。
  - 替换之前，现在的数据会存到数据文件夹的 `backups\` 里，文件名是 `GST-恢复前-<日期>-<时间>.db`，只留最近 3 份。
  - 旧版本的备份会自动升级。较新版本的备份、损坏的文件或 GST 正在使用的数据库会被拒绝并提示原因，什么都不改。
  - 重启后提示「已从备份恢复」。如果恢复的数据打不开，会保留原来的数据，提示「恢复没有完成，已保留原来的数据」。
  - 如果换文件时有文件一直被占用（比如被杀毒软件锁住），GST 会提示，并且什么都不打开，下次启动时再接着做完。数据不会丢。
  - 重启后用的是备份里的设置，开机自启也一样。
  - 只读的备份文件现在也能恢复。
- 「导出设置」和「导入设置…」带上这五个新设置，旧的设置文件照常导入。
- 键盘和高对比度主题：
  - 「启动时打开」「每周起始日」「主题」「主题色」「墨水屏配色」各占一个 Tab 停留点，用方向键、Home、End 在选项之间移动并选中。
  - 在 Windows 高对比度主题下，选中的颜色或配色外面有一圈高亮色。
  - 检查备份时「选择备份…」变暗。
- 图标只从本机带盘符的磁盘上的程序读取。从网络共享运行的软件显示名字的第一个字，不显示图标。
- 不改采集和口径：各页的时长算法不变，数据库结构仍为 schema 3。

## 隐私

「跟随 Windows」和它的色点要用 Windows 强调色，GST 只读注册表（`HKCU` 下的 `AccentPalette`，没有时读 `DWM\AccentColor`），不写注册表，颜色也不存进数据库。从备份恢复时，GST 只读你在打开对话框里选的那个文件，替换前的数据存进数据文件夹的 `backups\`，所有文件都留在这台电脑上。没有新增插件，不联网，也不上传任何东西。具体见 `PRIVACY.md`。

## 已知事项

「跟随 Windows」读到的真实强调色和「打开数据文件夹」要在装好的安装版里先确认一次。从网络共享运行的软件不显示图标，只显示名字的第一个字。

## 升级说明

数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。新设置没选过时都是默认值（蓝、极光、周一、概览、减少动画关闭），界面和 v0.4.3 一样。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.4_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.4_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
