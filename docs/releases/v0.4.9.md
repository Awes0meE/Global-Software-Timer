# Global Software Timer v0.4.9

- 时间的名字统一了：一种时间只用一个名字，写在 [时间的命名规范](../time-naming.md) 里。
  - **活跃**：窗口被选中，而且 5 分钟内有键盘或鼠标操作的时间。「概览」的今日活跃和软件的活跃都是这个意思。
  - **专注**：窗口被选中、在最前面的时间，人走开挂机也算。原来「软件」页的「今日活跃 / 共计活跃」其实是这个时间，现在改叫「今日专注 / 累计专注」，所以不会再和「概览」的今日活跃对不上；「统计」「成就」页原来叫「焦点」的也都改叫「专注」。
  - **窗口**：软件开着任务栏窗口的时间，不管有没有选中。原来的「前台」「窗口开着」都改叫「窗口」。
  - **后台**：没有窗口、进程还在跑的时间，缩在屏幕右下角的也算后台。
  - 「共计」统一改叫「累计」。
- 「概览」的状态改成「窗口运行 / 后台运行 / 未运行」：原来的「托盘运行」也显示为「后台运行」，用同一种指示灯。第一次关闭窗口时的选项「最小化到状态栏」改叫「最小化到后台」，和「设置」里一致。
- 「概览」右边「今日分布」的色条在深色主题下恢复了同色微光。各段在屏幕上是逐像素对齐的，但深色底上鲜亮的红色、黄色段看起来会比旁边高一点，所以深色主题下这两种颜色的段往下挪了半个物理像素；浅色主题不变。
- 「成就」页热力图的颜色拉得更开：用过的日子最浅从 30% 墨色起（原来是 20%），活跃 10 小时就是最深（原来要 12 小时）。
- 「设置」页读数屏的「已记录」「本机数据」字更大，并移到读数屏的正中间。
- 新记录一项数据：每个软件每天的后台时间里，有多少是只在屏幕右下角留个图标的时间。界面上仍然都叫「后台」，这个数先存着，留给以后的版本用；升级之前的日子没有这项数据。
- 不改口径：各页的时长算法不变，数据库结构仍为 schema 3。

## 隐私

不新增任何联网。新记录的那一项只是后台时长里的一部分，和其他时长一样只存在本机数据库里（`daily_software_runtime_usage.tray_seconds`），不读窗口标题，也不读右下角图标的提示文字。GST 唯一会联网的时候仍然是你点了「检查更新…」并在弹窗里同意，具体见 `PRIVACY.md`。

## 升级说明

已经装了 v0.4.6 及以后的版本，可以在「设置 → 关于与反馈 → 当前版本」点「检查更新…」，同意后一键升级到 0.4.9：GST 会先备份数据，再下载、校验签名、安装并重启。v0.4.5 及更早的版本没有「检查更新…」，需要手动下载安装一次。数据库结构不变（仍为 schema 3），只是在原有的表里加了一列，已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.9_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.9_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值，`latest.json` 是给「检查更新…」读取的版本清单。

## 代码签名 / Code signing policy

本版本的安装包没有代码签名，已向 SignPath Foundation 申请免费签名，详见 [代码签名政策 Code signing policy](../../CODE_SIGNING_POLICY.md)。
