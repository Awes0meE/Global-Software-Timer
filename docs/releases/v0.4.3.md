# Global Software Timer v0.4.3

- 概览「导出日报」改为下拉菜单，有两项：「日报海报」存成图片，「当日明细」就是 v0.4.2 的日报 CSV 表格，内容不变。
- 日报海报画的是正在看的那一天：日期，大字写那天的活跃时长（今天写「今日活跃」，往日写「当日活跃」），下面一条活跃占记录的进度条和「记录 X 小时」，最后是那天活跃最多的三个软件。那天没有活跃时间时，按运行时长排。隐藏软件和概览页一样不列。
- 成就页页头新增「导出成就」键，点开「成就海报」对话框：左边是海报的实时预览，右边列出所有到达里程碑的软件，档位高的在前，默认选中最近达到档位的那一个。可以用 ↑ ↓、Home、End 或直接打字找软件，回车、双击或点「保存图片」保存。
- 成就海报画一款软件：图标和名字、它到达的最高一档和达到的日期、「使用 N 天」和「累计专注 X 小时」。列表跟随成就页的「包含隐藏软件」开关；还没有软件到达里程碑时，「导出成就」键变暗，鼠标停上去提示「暂无里程碑」。
- 海报是 1080×1440 的 PNG 竖图，跟随 GST 当前的浅色或深色主题。上面只有软件名、图标、小时数、天数和日期，不写程序路径和进程名。字体是随应用打包的 Inter 和思源黑体（SIL OFL 1.1），只在画海报时用，界面字体不变。软件没有图标时画它名字的第一个字。
- 统计页「导出报表」也改为下拉菜单：
  - 「区间汇总」列出区间里有焦点、窗口或后台时间的所有软件，不再只列榜上的软件；新增「后台(小时)」和「使用天数」两列。当天焦点满 5 分钟算用了一天，只开着窗口或只在后台的日子不算。有排名的软件排在前面，按名次排。
  - 新增「每日明细」：每天每个软件一行，写那天的焦点、窗口和后台小时数。
  - 两个表格都跟随当前区间和「包含隐藏软件」开关。
- 海报和表格一样走 Windows 保存对话框，存好后提示「已保存」，可以点「在文件夹中显示」。「已保存」「保存失败」的提示现在画在对话框遮罩上面，在成就海报对话框里保存失败时，对话框不关，提示也看得清。
- 不改采集和口径：各页的时长算法不变。

## 隐私

海报在 GST 窗口里用本机的数据、随应用打包的字体和本机的图标缓存画出来，不联网，也不上传。和表格一样，只在你在保存对话框里点了保存后，写到你选的那个位置。每种文件的内容见 `PRIVACY.md`。

## 已知事项

海报里的真实软件图标要在装好的安装版里先确认一次；如果某个软件的海报上画的是名字首字而不是图标，请反馈。

## 升级说明

数据库结构不变（仍为 schema 3），已有的历史记录和设置全部保留。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.x、v0.4.x 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.4.3_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.4.3_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
