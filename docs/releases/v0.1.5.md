# Global Software Timer v0.1.5

Windows 10 / 11 x64

## 更新内容

- 同一个软件更新后会保留一份使用记录。原来按安装版本拆开的记录会在启动时合并，保留特别关注和隐藏设置。
- 计时器区分任务栏窗口、托盘软件和后台辅助进程。悬浮层和 Electron 子进程的识别更准确。Windows 11 支持托盘识别，Windows 10 使用窗口识别。
- 新增「后台」页，按软件查看当前 CPU、内存、进程数，以及当天的后台运行时长和 CPU 时间。
- 修复累计计时丢失不足一秒的余量、部分软件图标透明，以及查询历史时界面卡顿的问题。

## 安装与升级

日常安装请选择 **Global.Software.Timer_0.1.5_x64-setup.exe**。需要 MSI 部署时请选择 **Global.Software.Timer_0.1.5_x64_en-US.msi**。安装包未签名，Windows SmartScreen 可能提示未知发布者。

从 v0.1.4 升级前，请先从系统托盘退出程序并备份本地数据库。首次启动会将数据库升级到版本 2 并保留已有历史记录。v0.1.4 无法读取升级后的数据库，回退时需要升级前的备份。

## 验证

Windows 发布构建会按锁文件安装依赖，运行依赖审计、发布脚本回归检查、70 项前端测试、前端生产构建、Rust 格式检查及 119 项 Rust 测试，随后生成 EXE 和 MSI。下载后可用附件 SHA256SUMS.txt 核对安装包。
