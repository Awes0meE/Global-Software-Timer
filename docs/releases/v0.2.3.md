# Global Software Timer v0.2.3

- 概览按今日活跃时间选出「最常用」软件。如果今天还没有活跃记录，则按今日运行时间排序。
- 默认从概览中过滤 NVIDIA Overlay、AsHotplugCtrl、Razer Synapse Service Process 和 BitCenter。后台页仍可查看这些辅助进程，历史记录保留。
- 后台页以秒或分钟显示较短的 CPU 用时。概览预加载液晶屏的像素字体。
- 使用 EXE 安装包覆盖升级时，安装程序会刷新指向本程序的开始菜单和任务栏快捷方式图标。

## Windows 10 / 11 x64

现有 v0.2.x 用户可直接升级，沿用本机历史和设置。

- 常规安装或升级使用 `Global.Software.Timer_0.2.3_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.2.3_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
