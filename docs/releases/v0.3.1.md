# Global Software Timer v0.3.1

- 界面没有变化。这一版开始在本机逐段记录时间，为以后的「时间轴」页准备数据：
  - 每段时间里是哪个软件拿着焦点、电脑是否在活跃使用；
  - 每个软件哪段时间开着窗口（区别于只在托盘里运行）。
- 这些记录和每天的汇总在同一次写入里完成，按天累加起来与概览、软件页、统计页的时长一致。
- 隐私边界不变：只看窗口在不在，不读窗口标题、文档名或网页标题，不记录按键和鼠标位置；记录永久保存在本机，不联网、不上传。隐藏的软件照常记录，隐藏只影响页面显示。详见 `PRIVACY.md` 的「Timeline segments」一节。
- 时间轴页面会在之后的版本开放；在那之前，这些记录只在本机积累，不会显示出来。

## 升级说明

数据库会升级到第 3 版，已有的历史记录和设置全部保留。升级后不能再装回 v0.3.0 或更早的版本：旧版本会拒绝打开新版本的数据库。

## Windows 10 / 11 x64

现有 v0.2.x、v0.3.0 用户可以直接覆盖升级。

- 常规安装或升级使用 `Global.Software.Timer_0.3.1_x64-setup.exe`。
- Windows Installer 部署使用 `Global.Software.Timer_0.3.1_x64_en-US.msi`。

附件 `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。
