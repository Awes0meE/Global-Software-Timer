# Windows 桌面验收

运行 `npm.cmd run build`，再执行以下命令，在真实 WebView2 窗口测量概览首次数据显示和点击「软件」到列表绘制的时间。软件列表上限为一秒。验收同时检查设置页和 Windows 主窗口的大图标。

```powershell
cargo run --locked --manifest-path src-tauri/Cargo.toml --release --features tauri/custom-protocol --example gst_backlog_qa
```

默认使用 200 个模拟软件、3,200 段会话和 1,090 万条历史事件。本机已有数据库可通过 `GST_BENCH_DB` 指定；程序通过只读连接备份到临时目录，在快照上执行启动恢复。

## 已修条目（v0.2.1–v0.2.3）

| 条目 | 处理结果 |
| --- | --- |
| N1–N3 | N1 随 v0.2.1 发布。N2、N3 随 v0.2.3 发布：四个厂商辅助进程默认不进概览，「最常用」按今日活跃时长选出。 |
| N15、N16 | v0.2.3：后台页较短 CPU 时间显示秒或分钟；像素字体在 `index.html` 预加载。 |
| N4、N5、N10–N12、N14 | 概览与后台页区分加载、失败、空数据。台账与运行列表共用状态灯，后台表格使用时长偏好，并说明内存峰值。滚动区增加可访问名称；表盘顶部使用零点刻线。 |
| N6 | 保留按包分组，按固定规则选择代表程序，名称、进程和图标来自同一成员。 |
| N7–N9、N13 | 单次扫描异常会回滚，后续采样可继续。图标失败可重试。再次启动可跨安装目录唤出窗口，窗口枚举失败时保守计时。原生验收使用隔离快照。 |

## 覆盖安装后的图标（N18，v0.2.3）

安装包通过 `src-tauri/windows/installer-hooks.nsh` 的 `NSIS_HOOK_POSTINSTALL`，把开始菜单快捷方式和任务栏固定的快捷方式图标显式写成 `<安装目录>\global-software-timer.exe,0`，保留 AppUserModelID，再通知资源管理器刷新图标缓存。桌面快捷方式只在 `/UPDATE` 或静默/被动安装时保留显式图标；交互安装时完成页的“创建桌面快捷方式”会在钩子之后重新创建它（图标仍指向当前 exe，只是不是显式写法）。

验收：在已装旧版本的同一路径上覆盖安装新版本后，不注销、不重启，任务栏按钮和开始菜单都显示当前的时钟图标，不再是旧图标。
