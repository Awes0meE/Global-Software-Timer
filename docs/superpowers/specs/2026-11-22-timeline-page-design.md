## 目标与范围

开放侧栏「时间轴」。在单日里精确到秒地回答两件事：每一段时间焦点在哪个软件上，这一刻还开着哪些软件。

| --- | --- |
| 主视图：全天轨迹（焦点带、活跃带、并行波形、「这一刻」图标坞、软件泳道）、缩放、播放头 | 自动章节、两天叠加对比、导出 PNG、手动备注（这些以后再说） |
| 视窗台账 + 聚光；切换统计；专注块；空白解释 | 每日总量（在概览）、连续天数（在成就）、趋势（在统计）、单个软件历史（在软件页） |
| 回放页（整页表盘）和主视图上的回放预览卡 | 按时刻看后台进程 |
| 成就页热力图点某天，跳到该日时间轴 | 新的采集、schema 改动、目标、评分、提醒 |

## 缩放与语义阈值

- 可见跨度在 10 分钟到整天之间连续可调。整天按真实长度算，夏令时日是 23 或 25 小时。四个预设只是快捷入口；跨度不等于任何预设时，分段选择器不高亮任何一项。
- 点预设：24小时显示全天；其他预设以播放头为中心，碰到当天边界时夹紧。

| 跨度 | 语义变化 |
| --- | --- |
| > 8 小时 | 泳道只列当天焦点时长前 6 的软件，其余汇成一行：「另有 N 个软件在后台，放大到 8 小时以内全部展开」 |
| ≤ 8 小时 | 视窗内有运行区间的软件全部列出，泳道带弹性依次展开 |
| ≤ 1.5 小时 | 焦点段上标起止时刻 `HH:MM:SS`；放不下的段不标 |

## 播放头与输入

| 输入 | 行为 |
| --- | --- |
| 鼠标在轨迹上移动 | 播放头跟到鼠标所在时刻，身后留约 300ms 的余辉；鼠标离开后播放头留在原处 |
| 滚轮 | 缩放，鼠标下的时刻保持不动；跨度乘以 $1.0015^{\Delta y}$，再夹紧到 [10 分钟, 整天] |
| 拖动 | 平移视窗，不超出当天 |
| 双击 | 回到全天 |
| ← / → | 播放头移动 1 分钟；按住 Shift 时移动 10 分钟 |
| + / − | 以播放头为中心，跨度减半 / 加倍 |

- 初始播放头：今天放在「此刻」；其他日期放在当天最后一段记录的结束处。
- 轨迹容器设 `tabIndex=0` 和 `role="slider"`，`aria-valuemin` / `aria-valuemax` / `aria-valuenow` 为当天秒数，`aria-valuetext` 读作 `14:32:05，焦点 示例软件`（演示值）。
- 「此刻」：只在今天显示。画信号橙竖线和小灯，小灯复用现有 `lamp-breathe`。此刻之后的区域标「还没到」。
- 今天的数据每 60 秒刷新一次，用 `startVisiblePolling`（窗口不可见时停）。刷新时视窗、播放头和聚光都不变。

## 「这一刻」图标坞

坞跟着播放头横向移动，但不超出面板。图标用 DOM `<img>` 叠在画布上，因为 FLIP 动画需要 DOM。

时刻 $t$ 的两个判定（数据见「数据来源」，都在隐藏过滤之后）：

- **开着**：$t$ 落在该身份的 `intervals` 或 `window_intervals` 里。两者取并集，是因为会话起点是首次看到软件的 tick，窗口区间起点是认可区间的起点，边界上可能差几秒（v0.3.1 规格「已知限制」）；这样有窗口的软件一定算开着。
- **有窗口**：$t$ 落在该身份的 `window_intervals` 里。开着但没有窗口 = 托盘运行。

| 项 | 规则 |
| --- | --- |
| 焦点软件 | 40px，排第一，背后一圈本软件身份色的柔光；处于离开段时图标半透明。托盘软件拿到焦点时也按这一档 |
| 有窗口的软件 | 28px，不透明度 .95，下方 2px 身份色短条 |
| 托盘运行 | 22px，不透明度 .5，没有短条。纯后台进程没有会话，不进坞 |
| 逐段记录之前的时刻 | `before_collection` 的整天，以及 `collection_started` 当天 `collection_started_at` 之前：没有焦点和窗口数据，开着的软件一律 28px、不透明度 .95、不加短条，不分有窗口和托盘 |
| 排序 | 焦点 → 有窗口 → 托盘；同一档内按当天焦点时长降序，保证顺序稳定、FLIP 位移少 |
| 上限 | 最多 9 个图标，多出的显示 `+N` |
| 读数第一行 | 焦点软件名（13px / 650） |
| 读数第二行 | `本段 09:12:40–09:47:05 · 开着 7 个 · 有窗口 4 个`（演示值），时刻始终精确到秒。N = 此刻开着的软件数，M = 其中有窗口的数，焦点软件照常计入（托盘软件拿焦点时只计入 N） |
| 动画 | 弹入 300ms `cubic-bezier(.2,.8,.2,1.3)`；淡出 220ms；换位用 FLIP 平移，280ms；有窗口 ↔ 托盘只换档（大小、不透明度随 FLIP 一起过渡），不弹入淡出 |

播放头落在特殊区域时，读数第一行和第二行改为：

| 状态 | 第一行 / 第二行 |
| --- | --- |
| 还没到 | 还没到这个时刻 / — |
| 没在记录 | 「空白解释」里该空白的文案 / 空白起止 |
| 离开 | 离开 · 焦点仍在 示例软件 / 本段起止 |
| 有记录但没有可计入的前台软件 | 焦点：桌面或未识别软件 / 本段起止 |
| 逐段记录之前的日期 | 这一天还没有逐段记录 / `开着 N 个`（不写有窗口） |
| 采集上线当天、起点之前 | 逐段记录从 15:20 开始（演示值） / `开着 N 个`（不写有窗口） |

## 焦点带、活跃带、并行波形与泳道

- **焦点带**：画 `focus_segments`，颜色是该软件的身份色；离开部分（`segments` 里 `is_active = false`）叠斜线纹，宽度够的话标「离开」。`focus_identity_key` 为 null 且 `focus_hidden = false` 的段用中性灰浅纹；`focus_hidden = true` 的段见「隐藏软件口径」。没有记录的地方留空轨。
- **活跃带**：画 `active_segments`。活跃的地方实填；有记录但空闲的地方是淡轨；没有记录的地方不画。
- **时钟回拨**：回拨后同一天的段会在时间上重叠（v0.3.1 规格）。按返回顺序绘制，后画的覆盖先画的；播放头查询取覆盖该时刻的最后一段；台账照计秒数，与日汇总一致。
- **并行波形**：每个时刻开着的软件数（「开着」的判定见图标坞，含托盘，隐藏过滤之后），纵轴以当天最大值归一。不单独画有窗口的数。
- **泳道**：细线（2px）是开着的区间：`intervals`（同一身份多个 app_id 的重叠会话已由命令取并集，未关会话止于最近心跳）并上 `window_intervals`。其中有窗口的部分实画；只在托盘的部分（开着但不在 `window_intervals` 里）不透明度 .4。逐段记录之前的时刻分不出，整条实画。粗段（10px）是焦点段，离开的部分同样画斜线纹。
- **身份色**：v0.4.0 规格只规定 `--mix-1…7` 是软件身份色、同一页内同一软件颜色一致、旁边必须有软件名，没有定分配规则。本页按当天焦点时长排名把 `--mix-1…7` 依次发给前 7 个软件，其余用中性灰；同一软件在不同日期可能换色（「已定」3）。

## 空白解释

| 情况 | 判定 | 画法 | 文案 |
| --- | --- | --- | --- |
| 未来 | 今天、`generated_at` 之后 | 极淡底 | 还没到 |
| 未开机 | 不被任何段覆盖，且空白之后那一段 `start_reason = tracker_started` | 空轨 | 未开机 · 不记录；悬停说明：「关机或计时器没在运行」 |
| 休眠 | 同上，`start_reason = scan_gap` | 空轨 | 休眠或睡眠；悬停说明：「电脑睡眠、休眠或计时器卡住」 |
| 时钟调整 | 同上，`start_reason = clock_rollback` | 空轨 | 系统时钟被调过 |
| 没在记录 | 不被任何段覆盖，且当天之后再没有段（当天末尾，或今天最后一段到此刻） | 空轨 | 没在记录 |
| 离开 | `is_active = false` 的段 | 斜线纹 | 离开；悬停说明：「离开后的前 5 分钟仍算活跃」 |
| 桌面或未识别 | 有记录，`focus_identity_key` 为 null 且 `focus_hidden = false` | 中性灰浅纹 | 桌面或未识别软件 |
| 逐段记录之前 | 该日在采集起点之前 | 焦点带、活跃带位置写占位文字 | 这一天还没有逐段记录，只显示哪些软件开着 |

分不出关机与退出程序、睡眠与程序卡住（v0.3.1 规格「已知限制」），所以只按 `start_reason` 分上表几类，文案都带「或」，不再细分（「已定」2）。宽度不到 1 个物理像素的空白不单独画；相邻段起止有不足 1 秒的错位，不应该在图上出现断缝。跨午夜连续使用时，当天第一段 `start_reason = day_changed`，前面没有空白。

## 历史日期（逐段采集之前）

按命令的 `day_status` 分三种：`before_collection`、`collection_started`、`collected`。

- **整天在采集起点之前**（`before_collection`）：没有焦点、活跃和窗口数据（命令的 `window_intervals` 为空数组，意思是「没有记录」，不是「没有窗口」）。
  - 显示刻度尺、并行波形和泳道（只有细线，整条实画）。焦点带、活跃带的位置写占位文字。
  - 图标坞不放大任何图标，也不分有窗口和托盘，读数只写 `开着 N 个`（见图标坞）。
  - 视窗台账只留「软件」和「开着」两列，不显示「窗口开着」。「开着」= 该身份 `intervals` 与视窗交集的时长，含托盘；表头悬停说明「这一天还没有窗口记录，开着含托盘运行」。
  - 切换统计、专注块和摘要里的焦点数字都不显示。
  - 回放页可以进入，但只有图标轨道（不分有窗口和托盘），没有焦点环和活跃环。
- **采集上线当天**（`collection_started`）：`collection_started_at` 之前的时刻按上一条画（坞、泳道、回放都不分有窗口和托盘）；起点处在焦点带上标「逐段记录从 15:20 开始」（演示值）。台账照常五列，只算起点之后的数据；视窗包含起点之前时，标题行追加 `· 15:20 之前没有逐段记录`（演示值）。
- **完全没有记录的日期**：`segments` 和 `running` 都为空，整块面板显示空状态「这一天没有记录」。
- 日期 ◀ 最早只能到本机第一天有记录的日期（命令返回的 `first_recorded_date`；为 null 时 ◀ 不可用）；▶ 最多到今天。

## 视窗台账与聚光

台账统计的是当前可见视窗 $[a, b)$。标题行写 `统计范围 09:00 – 15:00 · 点一行可聚光`（演示值）。

时长一律用段的 `seconds`（认可秒数），不用起止差：段起止与秒数可差不到 1 秒，时钟小幅前跳时差得更多（v0.3.1 规格）。段只有一部分在视窗内时按比例取：

$$
s_{\text{视窗}}=\text{seconds}\times\frac{|[\text{start},\text{end})\cap[a,b)|}{\text{end}-\text{start}}
$$

这样视窗是整天时，「焦点」「其中活跃」两列之和与日汇总逐秒相等。

| 列 | 定义（「窗口开着」取 `window_intervals`，其余取 `segments` 并按上式裁剪到视窗） |
| --- | --- |
| 软件 | 图标 + 显示名，不加进程名 |
| 焦点 | 该软件段的秒数之和 |
| 其中活跃 | 该软件段里 `is_active = true` 的秒数之和 |
| 窗口开着 | 该身份 `window_intervals`（命令已按 1 秒容差取并集）与视窗交集的时长，即有窗口的时间，不含只在托盘的时间。这是区间长度，不按秒数比例取：整天视窗时与 `window_seconds`（= 统计页「开着没用榜」用的 `foreground_seconds`）可以差几秒，因为每个窗口段的起止与认可秒数差不到 1 秒；时钟回拨、身份合并（两个版本同时开着窗口）造成的重叠部分，并集后只算一次 |
| 切换进入 | 起点在视窗内、`start_reason = focus_changed`、焦点是该软件的段数。上一段是桌面或未识别也算；活跃↔空闲（`activity_changed`）、缺口后（`tracker_started` / `scan_gap` / `clock_rollback`）、跨午夜（`day_changed`）的第一段都不算 |

- **行**：视窗内焦点 > 0 或窗口开着 > 0 的软件，按焦点降序，焦点相同再按窗口开着降序。视窗内只在托盘运行、没拿过焦点的软件不进台账（泳道和坞里有）。采集前的日期按「开着」> 0 列出、按「开着」降序。
- **重算**：由纯函数 `ledgerForWindow(data, a, b)` 计算（隐藏过滤已由命令的 `include_hidden` 完成）。滚轮或拖动时每帧最多算一次（requestAnimationFrame 节流）。
- **聚光**：点一行，这个软件的焦点段、泳道和坞图标保持原样，其他软件降到不透明度 .25，过渡 180ms。
  - 再点同一行、按 Esc，或切换日期，都会取消。
  - 改缩放、移播放头时聚光保留。
  - 行上设 `aria-pressed`。
- **框选查账**：不单独做框选。把视窗缩放到哪一段，台账就是那一段的账。

## 切换统计与专注块

放在台账表格下面，作两行小结，跟随视窗重算：

- **切换**：`切换 87 次 · 最常见：示例A ⇄ 示例B 12 次`（演示值）。
  - 次数 = 视窗内 `start_reason = focus_changed` 的段数（含切进切出桌面或未识别）。
  - 切换对取这类段与它前一段的焦点身份，不分方向，列出前 3 对；任一端为 null（桌面或未识别、开关关闭时的隐藏软件）的不列。
  - 行尾小字：「每 5 秒采样一次，更短的切换不会被记下。」
- **专注块**：同一软件、`is_active = true`、中间没有缺口的连续焦点时间。按 v0.3.1 的写入规则，这正好是 `segments` 里的一行（焦点键非 null、`is_active = true`），不必再合并；按上式裁剪到视窗。必须严格首尾相连：中间夹了再短的切换（例如 10 秒）也算断开，不设最短时长。只列最长的 3 块，焦点带上不另作标记（「已定」6），写法如 `最长一段连续专注：示例A 10:05–11:32，1.5小时`（演示值）。不设门槛、不评分。

| 不用 | 改用 |
| --- | --- |
| 专注达标 / 专注得分 / 效率 | 最长一段连续专注 |
| 今天还差… / 再坚持… | （不出现） |
| 分心 N 次 | 切换 N 次 |

## 回放预览卡（主视图）

- 卡片里是 272px 的静态小表盘：焦点环和活跃环画到播放头为止，加上播放头时刻和焦点软件读数。
- 卡片本身不自动播放。
- 点卡片和点「回放」按钮效果相同。卡片设 `role="button"`，`aria-label` 为「进入回放」。

## 回放页

回放页是 TimelinePage 内部的一个视图（`view: "main" | "replay"`），不新增 PageId，侧栏仍高亮「时间轴」。

| 项 | 规则 |
| --- | --- |
| 进入 | 点「回放」或预览卡。共享元素转场：预览卡表盘用 FLIP 从卡片位置放大到整页表盘，主视图淡出、略微缩小，共 360ms；减少动画时直接切换。焦点落到「返回时间轴」 |
| 起点 | 回放从主视图播放头的时刻开始。如果起点已经在今天的此刻或当天末尾，按「播放」时从当天第一段记录开始 |
| 返回 | 左上角「← 返回时间轴」按钮；Esc 也能返回（页面上有对话框或弹层打开时，Esc 先关它们）。转场反向播放；返回后焦点回到「回放」按钮 |
| 恢复 | 日期、缩放跨度和聚光都恢复成进入前的样子。回放中时间有变化（播放过或拖动过）时，播放头放在回放停下的时刻，视窗只做最小平移把它包进来；否则播放头回到原处 |
| 表盘 | 一圈是一整天（按真实长度），00:00 在正上方，顺时针走；用玻璃表盘面。表盘面算一个顶层玻璃面板；图标圆片、读数区都不再加 `backdrop-filter`（v0.4.0 规格禁止嵌套模糊、同屏最多 6 个） |
| 刻度 | 按 v0.4.0 表盘规则：已走过的整点刻度用实墨，其他已走过的刻度用灰墨，没走过的用淡轨 |
| 焦点环与活跃环 | 外圈是焦点环（身份色，离开用斜线纹），内圈是活跃环。都随指针扫过逐段画出 |
| 中心 | 焦点软件的图标（64px）放大显示，背后是它身份色的光晕，下面写软件名；离开时显示「离开」 |
| 图标轨道 | 开着的软件以玻璃圆片图标绕圈排开，最多 12 个，多出的显示 `+N`；「开着」「有窗口」的判定同图标坞。有窗口的圆片正常大小；托盘运行的缩到 22/28 并降到不透明度 .5（比例同坞）；逐段记录之前的时刻不分，全部按正常大小。软件打开时从外圈飞入（400ms），关闭时往外飘出并淡掉（300ms）；有窗口 ↔ 托盘只缩放变淡（280ms），不飞入飘出 |
| 自动快进 | 没在记录的时段以 8 倍速度走过，中心写「没在记录 · 快进中」 |
| 此刻 | 只在今天显示：表盘边缘一个信号橙小点。回放走到此刻（今天）或当天末尾时自动暂停 |
| 跳转 | 点击或拖动表盘，按角度换算成时刻并跳过去 |
| 控件 | 播放/暂停（主按钮，空格键）；从头开始（Home）；速度分段 10分钟/秒、30分钟/秒、1小时/秒（默认 1小时/秒）；← / → 跳 1 分钟，Shift 跳 10 分钟 |
| 读数区（墨水屏） | 「回放到」大号像素数字 `HH:MM:SS`；日期；焦点软件卡（图标、名称、本段起止）；`开着 N 个 · 有窗口 M 个`（口径同坞；逐段记录之前的时刻只写 `开着 N 个`）；「截至此刻焦点」总时长（按隐藏软件开关过滤） |

## 动画清单

| 动画 | 触发 | 时长 / 缓动 |
| --- | --- | --- |
| 扫描式展开 | 首次载入、切换日期 | 600ms，从左到右点亮 |
| 泳道弹性展开 | 跨度跨过 8 小时 | 每条 320ms 回弹，依次错开 40ms |
| 缩放平滑 | 预设、滚轮、+/− | 指数趋近目标，约 150ms |
| 播放头余辉 | 播放头移动 | 300ms 淡出 |
| 坞图标弹入、淡出、FLIP | 播放头下开着的软件变化，或有窗口 ↔ 托盘换档 | 300 / 220 / 280ms |
| 聚光 | 点台账行 | 180ms |
| 页面转场 | 进出回放 | 360ms |
| 回放飞入 / 飘出 | 软件打开或关闭 | 400 / 300ms |

- 减少动画（`prefers-reduced-motion: reduce`）时：
  - 上表全部关闭，直接显示最终状态，没有余辉。
  - 回放仍能播放，因为这是用户主动发起的功能；只是图标直接出现或消失，没有飞入、飘出。
- 现有的全局规则 `styles.css:1856-1864` 只管 CSS 的 animation 和 transition，管不到画布逐帧绘制，也管不到 `Element.animate`。所以页面里要用 `matchMedia` 自己判断，并监听它的变化。

## 画布绘制

- **分工**：轨迹（刻度、三条带、泳道）和回放表盘的环画在 `<canvas>` 上。坞图标、表盘轨道图标、台账和读数用 DOM。
- **DPR**：后备尺寸取 `round(CSS 尺寸 × devicePixelRatio)`，再 `setTransform(dpr,0,0,dpr,0,0)`。
  - 1px 线条对齐到物理像素。
  - 用 ResizeObserver 监听容器（先例是 `TrendRecorder.tsx:160-168`）。
  - 用 `matchMedia("(resolution: Xdppx)")` 监听窗口在不同缩放的显示器之间移动。
  - 主题变化时重读 CSS 变量并重绘（`theme.ts` 的 `paint` 会改 `<html data-theme>`，用 MutationObserver 监听）。
- **绘制循环**：只在有变化时 requestAnimationFrame。动画结束后停循环；页面不可见时也停。
  - 画布上的文字用 `--font-num` / `--font-ui`，不用像素字（v0.4.0：GST Pixel 只在墨水屏内）；首次绘制文字之前等 `document.fonts.ready`。
  - 段数据预先按起点排序，播放头查询用二分查找。
- **无障碍**：画布设 `aria-hidden`。轨迹容器的 slider 读当前时刻和焦点；台账是真实表格；另加一段视觉隐藏的当日摘要。
- **测试环境**：jsdom 没有 canvas，`getContext` 返回 null 时跳过绘制、不报错。几何计算、台账、坞状态都写成可单测的纯函数。

## 隐藏软件口径

- **默认不显示隐藏软件**，与概览一致。全天轨迹面板标题行有「包含隐藏软件」开关，样式和行为与统计页（`StatisticsPage.tsx:152-163`）一致。切换开关时以新的 `include_hidden` 重新读取，视窗、播放头不变。
- **开关关闭时**（命令返回隐藏身份的焦点段为 `focus_identity_key = null`、`focus_hidden = true`，并去掉它的整个 `running` 条目（含窗口区间）和 `software` 条目）：
  - 泳道、坞、图标轨道、台账、并行波形、切换对、专注块，以及摘要和回放读数里的焦点数字，都不含隐藏软件。
  - `focus_hidden = true` 的段在焦点带上画成无名称的中性段，标「已隐藏软件」，免得看起来像离开、没记录或桌面，也不并入桌面或未识别（「已定」4）。这些秒数不进任何软件的焦点，也不进摘要的「焦点」；机器级的记录和离开照计。
  - 活跃带是机器级数据，不受开关影响。
- 原始记录照常保存，与 v0.3.1 规格和 `docs/CURRENT_STATE.md` L42 的口径一致。

## 时间格式

- **时长**：统一用 `formatDurationZh(秒, durationFormat)`，跟随设置里的时长格式。默认格式下是 `8.3小时`、`0.7小时`；选「小时分钟」格式时是 `42分钟`、`8小时35分钟`。
  - 决策书 5.5 要求「不满 1 小时用分钟」，与现有默认格式不符：`i18n.ts` 的小数格式总是用小时。按决策书「以现有设置为准」处理：默认格式下很短的时长照样显示 `0.0小时`，不改成分钟或 `<0.1小时`（「已定」5）。
- **时刻**：在 `src/i18n.ts` 新增共享的 `formatClock(date, withSeconds)`，输出本地 24 小时制 `HH:MM` 或 `HH:MM:SS`（仓库里目前没有共享的时刻格式化函数）。
  - 坞和回放里的段起止，以及跨度 ≤ 1.5 小时时的刻度和段标注，用 `HH:MM:SS`；其余用 `HH:MM`。
- **夏令时**：夏令时日里重复的本地时刻，刻度上照实出现两次；坞读数在时刻后附 UTC 偏移，例如 `01:30:00 (UTC−04:00)`。

## 验收标准

**前端测试（vitest）**

- 几何：时刻与 x 坐标互相换算；滚轮缩放后鼠标下的时刻不变；跨度夹紧到 [600 秒, 当天长度]；23 小时和 25 小时日的整天跨度正确。
- 阈值：跨度为 8 小时加 1 秒时，泳道是前 6 个加上「另有 N 个软件在后台…」；跨度为 8 小时时全部展开；跨度为 1.5 小时时有段起止标注，跨度为 1.5 小时加 1 秒时没有。
- 台账：
  - 视窗裁剪正确；
  - 同一身份重叠的运行区间取并集；
  - 「窗口开着」只算 `window_intervals` 与视窗的交集，只在托盘的时间不算；只在托盘、没拿过焦点的软件不出行；`window_intervals` 与 `intervals` 边界差几秒时，「开着」取并集；
  - 按比例裁剪：视窗切在段中间时取比例秒数；整天视窗时各列之和等于夹具里 `seconds` 之和（起止差与秒数不同的段也一样）；

  - 时钟回拨造成的重叠段：播放头查询不报错，台账照计秒数；

## 已知限制

- **采样间隔**：5 秒采样一次，短于 5 秒的焦点切换会漏掉，切换次数偏少。页面上要写明这一点。
- **空闲判定**：5 分钟没有键鼠输入才算离开，所以离开后的前 5 分钟仍算活跃，离开段整体会晚 5 分钟开始。
- **没在记录的原因**：只能靠空白后那一段的 `start_reason` 分两类。超过 10 秒的间隔一律是 `scan_gap`（`tracker.rs:136-145`、`314-321`），睡眠、休眠、程序卡住分不出；关机和退出程序都表现为 `tracker_started`。当天末尾的空白没有后一段，只能写「没在记录」。真实睡眠还没有验证过（`docs/CURRENT_STATE.md` L62）。
- **窗口与托盘**：v0.3.1 起由 `window_intervals` 区分；逐段记录之前的时刻没有窗口记录，也无法回填，只能显示「开着」（含托盘）。「有窗口」沿用任务栏 / Alt+Tab 规则：最小化和在别的虚拟桌面上的窗口也算，只说明软件有窗口，不说明是哪个窗口、在不在屏幕上。5 秒采样，短于 5 秒的窗口开合会漏掉。纯后台进程没有会话，不出现在泳道和坞里。
- **窗口开着与统计页**：台账「窗口开着」是区间长度，统计页「开着没用榜」是认可秒数，同一天可以差几秒（见视窗台账）。
- **锁屏**：锁屏期间仍算记录，焦点取当时的前台进程。
- **采集前的日期**：只有运行泳道，看不到焦点和活跃，也分不出有窗口和托盘。
