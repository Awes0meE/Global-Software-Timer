# 统计页与成就页设计草案

状态：头脑风暴结论，等待逐项细化。侧栏第六项由「日报」改为「成就」（奖杯图标），两页暂仍为未完成占位。

## 页面边界

| 页面 | 回答的问题 | 时间范围 |
| --- | --- | --- |
| 概览 | 今天用了多久、此刻在跑什么 | 今天 + 此刻 |
| 软件 | 某个软件的档案 | 今日 / 累计，单个软件 |
| 后台 | 后台进程今天占了多少资源 | 今天 |
| 时间轴 | 某一天里每一段时间在用什么、后台在开什么 | 单日，精确到秒的分解视图 |
| 统计 | 一段时间里时间花在哪、和以前比变了多少 | 用户选定的跨天区间 |
| 成就 | 长期积累了什么 | 全部历史；热力图默认近 90 天，可改 |

规则：统计和成就都不显示单独一天的时段内容，也不显示「此刻」。需要看某一天时，跳转到时间轴。

## 统计页

整页共用顶部区间选择：本周、本月、近 30 天、今年、自定义。

- **每日趋势**：区间内每天的记录时长与活跃时长，日均值，与上一个等长区间的环比。主图用走纸记录仪的形式。
- **区间排行与涨跌**：按区间活跃时长排名，标出新上榜、上升、下降。
- **活跃率走势**：活跃时长 / 记录时长。
- **开着没用榜**：区间内运行时间长、焦点时间短的软件。
- **会话分析**：每个软件的打开次数、平均单次时长、最长连续时长。
- **工作日与周末、作息**：日均对比，每天首次与最后一次使用时间，日均开机时长。
- **星期 × 小时习惯图**：多天叠加，只到小时精度，不能下钻到某一天。依赖半小时分时数据，排在最后。

## 成就页

- **日历热力图**：默认近 90 天，可切换到半年、一年。点阵 LCD 样式。点击某一天跳到该日时间轴。
- **连续使用天数**：当前连续天数与历史最长，从热力图读出。
- **个人纪录**：活跃最长的一天、最长的一次连续使用等。
- **里程碑**：例如某软件累计突破 100 小时。
- **软件来去**：新出现的软件、30 天未打开的软件，只给数量与名单入口，不复制软件页列表。

## 数据来源

| 模块 | 现有来源 |
| --- | --- |
| 趋势、活跃率、作息里的开机时长 | `daily_system_usage` |
| 排行、开着没用 | `daily_software_runtime_usage`、`daily_software_focus_usage` |
| 首次 / 最后使用时间 | `daily_software_runtime_usage.first_recorded_at`、`last_recorded_at` |
| 会话分析、单次纪录 | `usage_sessions` |
| 热力图、连续天数 | `daily_system_usage.active_seconds` |
| 星期 × 小时 | 待半小时分时数据 |

隐藏软件默认不计入排行与分布；两页可提供显式开关把隐藏软件计入（见 `memory.md`）。

## 不做

- 后台资源的长期趋势：后台页只有 2 天历史，以后放在后台页内。
- 导出 CSV 或报告、场景分类统计、记录覆盖率诊断：另开需求。
- 统计卡片网格：遵循 `DESIGN.md`，每页一个主图。
