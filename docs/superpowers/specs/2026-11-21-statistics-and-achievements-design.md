# 统计页与成就页设计草案

状态：已实现，随 v0.3.0（2026-11-22）发布。实现计划见 `docs/superpowers/plans/2026-11-21-statistics-and-achievements.md`，口径记在 `docs/CURRENT_STATE.md`。侧栏第六项由「日报」改为「成就」（奖杯图标），统计和成就两页都已开放。

## 页面边界

| 页面 | 回答的问题 | 时间范围 |
| --- | --- | --- |
| 概览 | 今天用了多久、此刻在跑什么 | 今天 + 此刻 |
| 软件 | 某个软件的档案 | 今日 / 累计，单个软件 |
| 后台 | 后台进程今天占了多少资源 | 今天 |
| 时间轴 | 某一天里每一段时间在用什么、后台在开什么 | 单日，精确到秒的分解视图 |
| 统计 | 一段时间里时间花在哪、和以前比变了多少 | 用户选定的跨天区间 |
| 成就 | 长期积累了什么 | 全部历史；热力图默认近 90 天，可改 |

规则：统计和成就都不显示单独一天的时段内容，也不显示「此刻」。需要看某一天时，跳转到时间轴。

## 统计页

整页共用顶部区间选择：近 7 天（默认）、本周、本月、近 30 天、今年、自定义。所有涨跌都与上一个等长区间比较，例如近 7 天对比再往前的 7 天；本月也一样，11-22 时本月（11-01 至 11-22）对比再往前的 22 天（10-10 至 10-31），不是上月同期。

- **每日趋势**：区间内每天的记录时长与活跃时长，日均值，与上一个等长区间的环比。主图用走纸记录仪的形式。
- **区间排行与涨跌**：按区间焦点时长排名，标出新上榜、上升、下降。软件维度统一用焦点，与开着没用榜、里程碑一致；机器维度（趋势、活跃率、热力图）用活跃。
- **活跃率走势**：活跃时长 / 记录时长。
- **开着没用榜**：只算有窗口的时间（`foreground_seconds`），不算托盘和后台时间，否则会被常驻服务占满。区间内窗口时长不少于 5 小时、且焦点时长不到窗口时长 5% 的软件才上榜，按「开着但没在用」的小时数排序。
- **会话分析**：每个软件的打开次数、平均单次时长、最长连续时长。
- **工作日与周末、作息**：日均对比，每天首次与最后一次使用时间（页面显示区间内的中位数），日均开机时长。
- **星期 × 小时习惯图**：多天叠加，只到小时精度，不能下钻到某一天。以后可以从逐段时间轴数据派生，只能从采集起点（v0.3.1）算起；不在 v0.3.1 做，排在最后。

## 成就页

- **日历热力图**：默认近 90 天，可切换到半年、一年。点阵 LCD 样式（v0.4.0 起为墨水屏）。点击某一天跳到该日时间轴，等时间轴页做好后再接。
- **连续使用天数**：当前连续天数与历史最长，按全部历史计算，不受热力图范围影响。活跃不到 5 分钟的日子按「没用」算，这只是过滤开机看一眼的噪声，不是目标。
- **个人纪录**：活跃最长的一天、单个软件单日焦点最长。不用「最长一次连续使用」：会话包含托盘运行，常驻软件的一次会话可以连续好几天。
- **里程碑**：按软件累计焦点时长计算，门槛为 10、50、100、500、1000 小时，6666 小时为终极成就。
- **软件来去**：新出现的软件、30 天未打开的软件，只给数量与名单入口，不复制软件页列表。累计窗口时长不满 1 分钟的软件不计入，挡掉只闪一下的安装包和临时程序。

## 视觉方向（2026-11-21 选定）

- 统计页：**A 走纸记录仪**。样稿含本机真实数据，未入库。
- 成就页：**B 日历刻度盘**，所有月份放在同一块液晶屏（v0.4.0 起为墨水屏）里，用刻线分隔，连续天数读数在屏幕右侧。样稿含本机真实数据，未入库。
- 区间选择器沿用 `DESIGN.md` 的分段选择器，当前项为 `--on` 底加 `--edge` 描边（v0.4.0 起），即 `.segmented-option.is-selected`。
- 6666 小时铭牌达成前和其他档一样是空槽（v0.4.0 起为内收虚线 `--edge-strong`，原为凹槽），不用信号橙；达成后用 `--accent` 描边（v0.4.0 起，原为信号橙）。
- 页头的单日日期按钮在统计、成就、软件、设置四页去掉，只留在概览和后台（2026-11-22 确认）。台账只显示软件名，不加进程名。

## 用词：只记录，不设目标

页面不能让用户觉得「今天必须用够多久」。5 分钟门槛是过滤噪声，文案按记录来写，不写成目标：

| 不用 | 改用 |
| --- | --- |
| 当天活跃满 5 分钟算用过 | 活跃不到 5 分钟的日子不算在内，免得开机看一眼也被记上 |
| 达标 / 未达标 | 用过 / 没用 |
| 8 月 达标 23/30 | 8 月 用过 23 天 |
| 近 90 天达标 56 天 | 近 90 天里用过 56 天 |

- 「当前连续 N 天」「最长连续 N 天」保留原说法；没用的日子格子的描边保留样稿样式。
- 页面上不出现「今天还差几分钟」、倒计时、「保持连续」之类的提示，也不发通知。

## 实现与样稿的差别

- 里程碑铭牌按「最高一档」摆放：每个软件只出现在它达到的最高一档上，带这一档的解锁日期；铭牌上的数量是达到这一档及以上的软件数。未点亮的铭牌写「未点亮」（样稿写「未达成」），显示累计焦点最多的软件到这一档的进度。
- 热力图里本机开始记录之前的日子画成一个暗点，标「无记录」，不当作没用；还没到的日子是虚线框。近一年视图格子缩小，月头只写「用过 N 天」，完整数字在悬停说明里。
- 成就页没做样稿里的近 30 天条带和「新」标记；个人纪录的范围写「全部历史」。排行行只显示图标和显示名，不显示进程名。
- 热力图点某天跳时间轴、星期 × 小时习惯图仍未做，见实现计划的「不做」。

## 数据来源

| 模块 | 现有来源 |
| --- | --- |
| 趋势、活跃率、作息里的开机时长 | `daily_system_usage` |
| 排行、开着没用 | `daily_software_runtime_usage`、`daily_software_focus_usage` |
| 首次 / 最后使用时间 | `daily_software_runtime_usage.first_recorded_at`、`last_recorded_at` |
| 会话分析 | `usage_sessions` |
| 热力图、连续天数、活跃最长的一天 | `daily_system_usage.active_seconds` |
| 里程碑、单个软件单日焦点最长 | `daily_software_focus_usage` |
| 软件来去 | `daily_software_runtime_usage.foreground_seconds` 的首末日期与累计 |
| 星期 × 小时 | 以后从 `timeline_segments` 派生，只能从采集起点（v0.3.1）算起 |

隐藏软件默认不计入排行、开着没用、会话、里程碑等软件维度的列表；两页都有「包含隐藏软件」开关，机器级数字不受影响，逐项口径见 `docs/CURRENT_STATE.md`。

本机的每日总时长从 2026-05-29 开始，软件的焦点与前后台拆分从 2026-06-18 开始。区间覆盖这段早期日期时，总时长照常显示；软件排行和焦点相关的数字把这些日期标为「无软件明细」，不计入，也不当作 0。

## 不做

- 后台资源的长期趋势：后台页只有 2 天历史，以后放在后台页内。
- 导出 CSV 或报告、场景分类统计、记录覆盖率诊断：另开需求。
- 统计卡片网格：遵循 `DESIGN.md`，每页一个主图。
